# Jobs to Be Done

People don't buy products — they "hire" them to make progress in a specific situation.
Your job is to uncover that progress, then design for it.

## Process

### 1. Frame the job
Write the core job as: **"When [situation], I want to [motivation], so I can [expected outcome]."**
Name the job performer (who), the context (when/where), and what they hire today.

### 2. Decompose into three layers

| Layer | Question | Example (hiring a designer for a landing page) |
|---|---|---|
| **Functional** | What must get done, measurably? | A page that converts visitors into leads |
| **Emotional** | How do they want to *feel* (and avoid feeling)? | Confident, not anxious about launch day |
| **Social** | How do they want to be *seen* by others? | Look credible to investors and peers |

For each layer list 3–5 items, and the **current pains** and **workarounds**.

### 3. Map the job steps
Define → Locate → Prepare → Confirm → Execute → Monitor → Modify → Conclude.
Mark the steps where people struggle, waste time, or give up.

### 4. Find the forces
- **Push** of the current situation (frustration)
- **Pull** of the new solution (attraction)
- **Anxiety** about switching
- **Habit** of the present

A solution wins only when Push + Pull > Anxiety + Habit.

### 5. Generate 10x options
For each underserved need ask:
- What if this step disappeared entirely?
- What if it took 10x less time, money, or effort?
- What would make them *proud* to tell others (social job)?
- What would remove the anxiety completely (emotional job)?

Propose 3 options: **incremental**, **bold**, **10x**. Rate each on impact vs effort.

## Output format
1. Job statement
2. Functional / Emotional / Social table
3. Job map with struggle points
4. Forces diagram
5. Three solution options + recommendation and the first experiment to validate it

Answer in the user's language.
