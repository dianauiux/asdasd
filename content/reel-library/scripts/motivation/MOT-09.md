# Reel MOT-09 — Սովորիր հեռանալ

**Բաժին:** Motivation  
**Երկրորդական թեմա:** Relationships  
**Թիրախային տևողություն:** 25–30 վայրկյան  
**Կարգավիճակ:** Նկարահանման սցենար՝ առանց վերջնական ժամաչափման

## Սցենար

«Երբեմն ամենադժվար որոշումը հեռանալն է այն մարդկանցից, որոնց շատ ես սիրում։

Որովհետև անընդհատ մտածում ես՝ գուցե փոխվեն, գուցե մի օր հասկանան, թե որքան կարևոր են քեզ համար։

Ու շարունակում ես ներել, սպասել, փորձել ամեն ինչ շտկել։

Բայց մի օր հասկանում ես, որ հարաբերությունը միայն մեկ մարդու ջանքերով պահել հնարավոր չէ։

Երբեմն հեռանալը պարտություն չէ։

**Դա այն պահն է, երբ վերջապես սկսում ես հարգել նաև ինքդ քեզ։**

Ու հիշիր՝ դու էլ ես արժանի այն հոգատարությանը, որը տալիս ես ուրիշներին»։
