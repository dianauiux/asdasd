# DEE DESIGN / PIXEL ACADEMY — REELS LIBRARY

Այս փաթեթում՝ **10 մոտիվացիոն Reel**, յուրաքանչյուրը առանձին Markdown ֆայլով։

## Բացել և օգտագործել

- `index.html` — բացիր բրաուզերում. կան թեմատիկ tab-եր, որոնում և ամբողջ սցենարի դիտում։
- `Reels_Content_Tabs.xlsx` — նույն բովանդակությունը Excel/Google Sheets tab-երով։
- `reels.json` — կառուցվածքային տվյալներ Claude-ի կամ կայքի համար։
- `scripts/motivation/MOT-01.md` ... `MOT-10.md` — առանձին սցենարներ։
- `CLAUDE_INSTRUCTIONS.md` — պատրաստ հանձնարարություն Claude-ին։

## Դասակարգման սկզբունք

Մոտիվացիոն 10 սցենարները բոլորը հիմնական **Motivation** բաժնում են։ Յուրաքանչյուրն ունի երկրորդական թեմա՝ `Personal & Life`, `Career & Work` կամ `Relationships`։ Չկրկնօրինակել նույն Reel-ը տարբեր tab-երում. երկրորդական թեման օգտագործել ֆիլտրի համար։

## Ապագա թեմատիկ ներդիրներ

`Personal` · `Career` · `UX UI Tricks` · `AI Tools` · `Design History` · `Business Clients` · `Courses` · `Real Projects` · `Relationships`

Ներկայում այդ բաժինները դատարկ են, որպեսզի Claude-ը չհորինի կամ չվերագրի սցենարներ։
