Copy արա, փոխիր [քառակուսի փակագծերը] և ստացիր դիզայն, որ նման չէ «AI-ի դիզայնի»։

01
Landing page-ի ճիշտ brief
Ով է օգտատերը, ինչ պետք է անի, ոճը, և 3 ուղղություն մինչև կոդը։
Design a landing page for [product].
Users: [who they are]. Goal: [one action they should take].
Style: [2–3 words], one accent color [#hex], references: [site 1], [site 2].
Give me 3 different visual directions first, with a short explanation each.
Don't build the full page until I choose one.
02
Միայն քո դիզայն համակարգով
Claude-ը չի հորինում նոր ոճ, եթե ինչ-որ բան պակասում է։
Here is our design system: colors, fonts, buttons and cards (attached).
Design a [page] using only these tokens and components.
If something is missing, tell me instead of inventing a new style.
03
Վերցրու կայքի ոճի կանոնները, ոչ թե կոդը
Սկզբունքներն ես վերցնում, ոչ թե ուրիշի դիզայնը։
Analyze this screenshot. Extract the design system only:
type scale, spacing scale, number of colors, corner radius, motion durations.
Don't copy content or layout. Apply these rules to my brand: [colors, fonts].
04
«Թրենդային» 4 բառով
Տիպոգրաֆիկա, տարածություն, մեկ գույն, թեթև շարժում։
Redesign this section to feel current, not generic:
- typography: very large headline, tight letter spacing, one font family
- space: at least 120px between sections
- color: neutral base, one accent color only
- motion: subtle hover animation on buttons and cards (200ms ease)
Keep the content the same.
05
Motion spec, հետո կոդ
Թվերով animation-ը թանկ տեսք ունի։
Before coding, write a motion spec table:
element, trigger, duration (ms), easing (cubic-bezier), delay/stagger.
Use 150–400ms and one easing curve for the whole page. Then implement it.

06
Scroll animation առանց JavaScript-ի
CSS scroll-driven animations, ժամանակակից բրաուզերներում։
Animate each section as it enters the viewport using CSS
scroll-driven animations (animation-timeline: view()). No JavaScript.
Add a fallback for unsupported browsers and respect prefers-reduced-motion.
07
Անվանիր գործիքը
GSAP, Lenis, Framer Motion. Անունը փոխում է արդյունքը։
Use GSAP with ScrollTrigger: pin the hero, scale the product image
from 0.8 to 1 while scrolling, then release.
Add Lenis for smooth scrolling.
08
Hero animation մեկ ֆայլով
Տառ առ տառ վերնագիր և շարժվող գրադիենտ։
Create a hero section animation in HTML and CSS only:
- the headline appears letter by letter, 40ms per letter
- the background is a slow-moving gradient (pink to orange), 12s loop
- respect prefers-reduced-motion
Give me one file I can open in the browser.
09
Claude-ը որպես art director
Թող քննադատի, հետո ուղղի ամենակարևորը։
Act as a senior art director. Critique this page harshly:
hierarchy, spacing, contrast, consistency.
List the 5 biggest problems by impact, then fix only the top 3.
10
Թող ինքը ստուգի իր աշխատանքը
Screenshot երկու չափսով և ուղղումներ։
After you build it, open the page in a browser, take screenshots
at 390px and 1440px, compare them with the reference,
and fix the top 3 differences. Show me before and after.
