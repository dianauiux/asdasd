Accessibility Claude-ով
Audit this page for accessibility (WCAG 2.2 AA).

Check:
- Text contrast (at least 4.5:1 for body text)
- Tap target size (aim for 44×44 px; the WCAG 2.2 AA minimum is 24×24 px)
- Missing alt text and form labels
- Keyboard focus visibility

List each problem with the element, why it matters, and the exact fix. Then apply the fixes without changing the visual style.
