## 3 · Reel · 5 Figma կոմբինացիա, որ ժամեր կխնայեն

**Ձևաչափ.** էկրանի ձայնագրություն Figma-ում, 25–30 վրկ, յուրաքանչյուր կոմբինացիա՝ 4–5 վրկ, ստեղները մեծ տառերով էկրանին։

| Կոմբինացիա (Mac / Windows) | Ինչ է անում |
|---|---|
| Shift + A | Ավելացնում է Auto Layout |
| ⌘ + ⌥ + K / Ctrl + Alt + K | Ստեղծում է կոմպոնենտ |
| ⌘ + ⌥ + G / Ctrl + Alt + G | Ընտրվածը դնում է frame-ի մեջ |
| Shift + 2 | Մոտեցնում է ընտրված տարրին |
| ⌘ + / / Ctrl + / | Բացում է Quick actions որոնումը |

- **0–2 վրկ, էկրանին.** 5 Figma կոմբինացիա, որ ժամեր կխնայեն
- **Վերջ.** Պահպանիր և փորձիր այսօր։ Ո՞րն էիր արդեն օգտագործում։

```
5 Figma կոմբինացիա, որ ժամեր կխնայեն 👇

1. Shift + A՝ Auto Layout
2. ⌘ + ⌥ + K (Ctrl + Alt + K)՝ կոմպոնենտ
3. ⌘ + ⌥ + G (Ctrl + Alt + G)՝ frame ընտրվածի շուրջ
4. Shift + 2՝ մոտեցնել ընտրված տարրին
5. ⌘ + / (Ctrl + /)՝ Quick actions՝ ցանկացած գործողության որոնում

Պահպանիր գրառումը և փորձիր դրանք այսօր։

Ո՞ր կոմբինացիան էիր արդեն օգտագործում։ Գրիր մեկնաբանություններում։
```

## Ինչու են այս գրառումները աշխատելու
- **Կոնկրետ թվեր** (44, 4.5:1, 8, 16, 45–75). մարդիկ պահպանում են այն, ինչ կարող են կիրառել։
