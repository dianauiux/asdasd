## Productized packages

### 1. UX Audit ("Fix the Leaks")
For products with traffic but weak conversion or activation.
- Heuristic review of up to 3 key flows, plus a Loom walkthrough
- A prioritized issue list (impact × effort) with redesign sketches for the top 5 issues
- **Timeline:** 5 business days · **Price:** $700–1,200 (~20–30h)
- *Great first step and upsell entry point.*

### 2. Landing Page / Marketing Site
- Discovery, wireframes, UI (desktop + mobile), and handoff (or a Framer build if offered)
- **Timeline:** 1–2 weeks · **Price:** $1,200–2,400 (~30–60h)

### 3. MVP Product Design
For founders going from idea to a build-ready product.
- Discovery workshop, user flows, wireframes, UI for core screens, a clickable prototype, and a starter design system
- **Timeline:** 4–6 weeks · **Price:** $4,200–8,000 (~120–200h)

### 4. Redesign & Design System
- Audit, a new visual direction, component library (Figma variables + light/dark modes), and key screen redesigns
- **Timeline:** 4–8 weeks · **Price:** $5,000–11,000 (~140–280h)

### 5. Design Partner Retainer
- A set number of design days per month, async Slack, and a weekly sync
- **Price:** $2,100–4,800 / month (60–120h at $35–40/h) (minimum 3 months)
